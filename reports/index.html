최초 1회 필요 - GitHub 토큰 발급 방법
  1. GitHub 토큰 발급 페이지 접속
  2. Token name: 아무 이름 (예: stockagent-web)
  3. Expiration: 원하는 기간 선택 (예: 90 days 또는 No expiration)
  4. Repository access: "Only select repositories" 선택 → 아래 목록에서 oysking55-ctrl/stockagent 체크
  5. Permissions 펼치기 → Repository permissions 아래에서 Actions 줄만 찾아 Read and write 로 변경 (다른 항목은 전부 No access 그대로 둠)
  6. 맨 아래 Generate token 클릭
  7. 표시되는 토큰 값 복사(다시 못 보니 꼭 지금 복사) → 위 "토큰 설정" 버튼을 눌러 붙여넣기
